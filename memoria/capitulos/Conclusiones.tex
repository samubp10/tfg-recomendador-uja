\section{Limitaciones}
\label{secc:limitaciones}

\textcolor{borrador2}{Lo que sigue es la lista de lo que este trabajo no
  cubre. Cada una se razona donde se produce, junto al resultado que la provoca
  ---en el Apartado~\ref{secc:amenazas_validez} del capítulo anterior---; aquí
  se enuncian juntas para que el lector no tenga que reconstruirlas.}

\begin{itemize}
  \item \textcolor{borrador2}{\textbf{El sistema no se ha probado con
      usuarios.} Se evalúa con un banco de preguntas escrito para este trabajo,
    lo que deja sin comprobar si un estudiante formula sus dudas como están
    escritas esas preguntas, si entiende la respuesta y si le sirve para
    decidir.}

  \item \textcolor{borrador2}{\textbf{Lo que se comprueba de cada respuesta es
      que no invente y que nombre lo que debía}, no que sea buena. Una respuesta
    correcta, fundamentada y poco útil pasa todas las comprobaciones.}

  \item \textcolor{borrador2}{\textbf{El banco de evaluación es propio y lo ha
      escrito la misma persona que escribió el corrector.} Es el límite del
    instrumento, y a lo largo del desarrollo produjo varias veces cifras
    verosímiles que solo se descubrieron leyendo respuestas a mano.}

  \item \textcolor{borrador2}{\textbf{Los tiempos de respuesta no son
      extrapolables a otro equipo.} Se miden sobre el ordenador personal en el
    que se desarrolla el trabajo, que es también el equipo doméstico que impone
    el requisito RNF-01, y ahí la mediana dobla el umbral fijado.}

  \item \textcolor{borrador2}{\textbf{La colección cubre un solo centro y no
      todas sus titulaciones por igual.} Las asignaturas sin guía publicada se
    concentran en las titulaciones en implantación, de modo que el sistema sabe
    menos precisamente de las más nuevas.}

  \item \textcolor{borrador2}{\textbf{La aplicación web no está en condiciones
      de producción.} Sirve para demostrar y para probar el sistema, no para
    abrirla a usuarios: atiende las peticiones de una en una, no cifra el tráfico
    y escucha solo en la máquina local.}
\end{itemize}

\section{Trabajo futuro}
\label{secc:trabajo_futuro}

\textcolor{borrador2}{Cada línea que sigue responde a una limitación de la
  lista anterior, y por ese orden. No se enuncia ninguna que no se siga de algo
  que este trabajo haya encontrado.}

\begin{itemize}
  \item \textcolor{borrador2}{\textbf{Probar el sistema con estudiantes de
      secundaria, antes que cualquier otra cosa.} Es el paso que falta para
    saber si el sistema sirve para lo que se construyó, y el que debería
    preceder a ponerlo en producción.}

  \item \textcolor{borrador2}{\textbf{Medir la utilidad de la respuesta y no
      solo su fidelidad}, que es lo que exige a su vez la validación con
    usuarios: sin alguien que juzgue si una respuesta le resolvió la duda, no
    hay forma de puntuar eso de manera determinista.}

  \item \textcolor{borrador2}{\textbf{Que el banco de preguntas y sus
      respuestas correctas los escriba alguien distinto de quien escribe el
    corrector.} Es lo único que levanta de verdad la duda sobre el instrumento;
    repetir las mediciones no la levanta.}

  \item \textcolor{borrador2}{\textbf{Reducir el tiempo de respuesta} hasta el
    umbral que la hipótesis fijaba y que no se cumple. Hay dos caminos que este
    trabajo no ha explorado: aprovechar la tarjeta gráfica para la inferencia, y
    reducir el número de llamadas al modelo por turno, que hoy son dos.}

  \item \textcolor{borrador2}{\textbf{Extender la colección al resto de centros
      de la Universidad.} El diseño lo admite ---basta añadir fuentes a la
    extracción, sin tocar el núcleo de recuperación y generación---, pero que el
    sistema mantenga su rendimiento con una colección varias veces mayor
    \textbf{no está medido}, y es lo que habría que comprobar antes de
    prometerlo.}

  \item \textcolor{borrador2}{\textbf{Llevar la aplicación a condiciones de
      producción}: un servidor preparado para atender en paralelo, tráfico
    cifrado y límites de tamaño y de frecuencia por cliente.}
\end{itemize}
